# Round 7 — 병변 슬라이스 오버샘플링 ★ 최종 모델 (combined 0.92295)

## 분석에서 출발
R6 이후 4분면을 다시 보니 여전히 가장 약한 칸은 bbox, 특히 bbox_acc8이었다. 병변 데이터를
분석했다.
- 전체 슬라이스 4651장 중 병변 박스가 있는 슬라이스는 1824장(약 39%)뿐. 나머지 61%는 병변이
  없어, 학습 gradient의 대부분이 "병변 없는 해부구조"에 쓰이고 있었다.
- 즉 채점에서 큰 비중(bbox 50%)을 차지하는 병변을, 모델은 상대적으로 적게 보고 있었다.

## 해법 — 병변 슬라이스 오버샘플링
병변 박스가 있는 슬라이스를 학습 데이터셋에 더 자주 등장시킨다(단순 복제 2배). load_data_bbox.py에
이미 lesion_sample 메커니즘이 있어 이를 켜는 방식.

핵심 시너지: 복제된 병변 슬라이스도 R6의 마스크 증강을 그대로 받는다. 따라서 같은 병변을
**여러 언더샘플링 조건에서 복원하는 연습**이 되어, bbox_acc8을 곱셈으로 겨냥한다.

## 실험 방법 — 대조군으로 교란 분리
단순 복제는 병변 슬라이스를 2배 넣으므로 에폭 크기가 4651 → 약 6475로 커진다(스텝 39% 증가).
그러면 "성능이 올라도 병변 강조 때문인지 그냥 스텝이 늘어서인지" 알 수 없다. 이 교란을 걷어내려고
**대조군을 함께** 돌렸다.
- **F1_lesion:** 병변 슬라이스를 복제해 6475 (표적 실험).
- **F2_control:** 병변이 아닌 무작위 슬라이스를 복제해 같은 6475 (병변 강조 없이 스텝만 동일 증가).
- 두 arm의 차이는 "무엇을 복제하는가"뿐. 따라서 F1−F2 = 순수 병변 효과, F2−R6 = 순수 스텝 증가 효과.
- 백본 c6/ch9 30ep, R5 전경 손실·R6 마스크 증강 유지. 기준선 R6 = 0.92195.

## 결과 분석
- **효과 분리가 깨끗하게 나왔다:**
  - F1 − R6 = +0.0010 (병변 오버샘플링 전체 효과)
  - F2 − R6 = **-0.0001** (스텝 39% 증가만으로는 효과 없음)
  - F1 − F2 = +0.0011 (순수 병변 강조 효과)
  → 이득은 온전히 "병변을 더 본 것"에서 왔다. 동시에 "에폭/스텝 레버는 소진"이라는 R4 결론이
    대조군으로 재확인됨.
- **표적 적중:** 네 칸 중 bbox_acc8이 +0.0015로 가장 크게 올랐다(우리의 최대 약점). acc4 강점도
  훼손되지 않았다(오히려 상승).
- **라벨별 관찰:** 개선이 고르지 않았다. 개수가 적은 희귀 라벨(Displaced Meniscal Tissue,
  Bone-Lesion 등)이 크게 오른 반면, 많이 복제된 상위 라벨(Meniscus Tear, Joint Effusion)은
  이미 잘하고 있어 소폭에 그쳤다. "이미 잘하는 것을 더 복제하는 것은 낭비"라는 힌트(후속
  개선 여지로 기록).

## 최종 성적
- **combined 0.92295**, official_est 0.9239. 4분면: full_acc4 0.9459 / bbox_acc4 0.9449 /
  full_acc8 0.9048 / bbox_acc8 0.8961. 추론 속도 약 245 ms/slice.
- 이 모델을 최종 모델로 채택.

## 사용한 코드 (핵심)
```python
# load_data_bbox.py — 병변 슬라이스를 복제해 데이터셋에 추가
for slice_ind in range(num_slices):
    boxes = annotations.get(str(slice_ind), [])
    copies = repeat if lesion_sample and boxes else 1
    self.examples.extend(
        (image_fname, kspace_fname, slice_ind) for _ in range(copies)
    )
```

## 프로젝트 전체를 관통한 방법론
Round 1의 0.9126에서 시작해, 매 라운드 한 번에 하나의 가설만 검증하고 대조군·4분면 분해로
원인을 귀속하며 최종 0.92295에 도달했다. 핵심은 "모델을 더 크게"가 아니라 "낭비를 제거하고
채점·데이터에 정렬"하는 것이었다 — 충분한 학습 시간(R3), 리더보드 4분면 판정(R4),
채점식과 일치하는 전경 손실(R5), 데이터 분포 이동을 고친 마스크 증강(R6), 그리고 병변을
직접 겨냥한 오버샘플링(R7).
