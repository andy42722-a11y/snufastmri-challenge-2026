# Round 6 — 마스크 증강 (샘플링 분포 이동 교정) ★ 최대 도약

## 데이터 정밀 분석에서 출발
"데이터를 잘 분석하는 팀이 이긴다"는 문제의식으로, 학습 데이터와 리더보드 데이터의 샘플링
마스크를 전수 비교했다. 각 kspace 파일의 mask 배열을 해시로 집계해 종류를 셌다.

- 언더샘플링 마스크는 "중앙 ACS(연속 샘플링) 블록 + 바깥의 등간격 격자" 구조. 변하는 것은
  격자의 **위상 오프셋(offset)**, ACS 폭, k-space 너비 W.
- **학습 acc8 마스크의 오프셋은 {0,1,2}에 쏠려 있었다(0이 61%).** 반면 **리더보드 acc8은
  오프셋 0~7에 고르게 퍼져 있었고, 40볼륨 중 대부분이 학습에서 본 적 없는 오프셋**을 썼다.
- ACS 폭도 어긋났다: 학습은 {26,28,29,31,33,39}, 리더보드 최빈값 30은 학습에 아예 없었다.

**왜 치명적인가:** 등간격 언더샘플링은 이미지에 결맞은(coherent) 앨리어싱 — 일정한 위치의
유령 복제 — 을 만든다. 그 위치는 오프셋에 따라 달라진다. 오프셋 {0,2}만 학습한 모델에게
오프셋 4를 주면 유령이 엉뚱한 곳에 나타나는 셈이다. 그동안 "acc8은 원래 어렵다"고 여겼던 것의
상당 부분이 사실은 **안 배운 패턴을 시험 본 것(분포 이동)**이었다.

## 완전 샘플링 확인 (해법의 전제)
해법이 가능하려면 학습 k-space가 완전 샘플링이어야 한다. 이를 세 가지로 검증했다.
- 마스크를 곱하지 않고 raw k-space를 역변환(ifft→RSS→crop)했을 때 정답 image_label과
  **SSIM = 1.0, 상대오차 약 1e-7** — 완전 일치.
- 고에너지 대역에서 mask==0 열과 mask==1 열의 에너지가 사실상 동일(비율 약 1.0).
- 실제로 에너지가 0인 열은 최고주파 가장자리 소수뿐(마스크와 무관).

→ **학습 데이터에 우리가 원하는 어떤 언더샘플링 마스크든 씌울 수 있다.** 게다가 acc4 볼륨도
완전 샘플링이므로 acc8 마스크를 씌워 "새 acc8 학습 예시"로 만들 수 있다.

## 해법 — 학습 시점 마스크 증강
매 학습 스텝마다 마스크를 무작위로 새로 생성해 씌운다.
- 주기 p: {4, 8} 중 50:50(채점식이 acc4:acc8 = 50:50이므로).
- 오프셋: 0~p-1 균등(학습에 없던 오프셋까지 고르게 커버).
- ACS 폭: 관측 범위 [26,33]에서 균등, 중앙 대칭(감도맵 추정 로직이 대칭을 전제).
- 재현성: (seed, epoch, 파일명, slice) 해시에서 파라미터를 유도(전역 RNG 미사용).
- 삽입 위치: transforms_bbox의 `input * mask` 직전 한 줄만 교체하면 k-space 재마스킹·모델 입력
  마스크·데이터 일관성·감도맵 추정이 모두 같은 마스크를 쓴다. val은 증강하지 않음.

**규정 준수:** 리더보드 마스크를 직접 읽어 쓰거나 그 빈도를 하드코딩하지 않았다. train/val의
샘플링 원리(주기·오프셋·ACS·W)에서 균등 생성만 했다. 생성 가능한 마스크가 리더보드 조합의
약 96%를 자연히 포괄했다(유일한 미포괄은 학습에 존재하지 않는 W=400 1볼륨).

## 실험 방법
- 백본 c6/ch9 30ep. R5 전경 손실 유지. 기준선 R5 = 0.9179.
- 에폭 크기(4651)를 그대로 유지 — 샘플을 추가하지 않고 각 샘플의 마스크만 매번 새로 뽑음.
  덕분에 gradient 스텝 수가 R5와 동일해 "스텝 증가" 교란이 없다.
- 사전 검증: 학습 데이터의 실제 마스크 12종을 (W, 주기, 오프셋, ACS폭)으로 재생성해 원본과
  **해시(md5)가 12/12 일치**하는지 확인. 생성기가 주최측 마스크와 물리적으로 동일함을 보장.

## 결과 분석
- combined +0.0040 — 단일 라운드 최대 상승폭. 채택.
- **인과 증거:** 리더보드 acc8 40볼륨을 "학습에서 본 오프셋(0,1,2)" 14볼륨과 "미학습 오프셋
  (3~7)" 26볼륨으로 나눠 비교했더니, 미학습 그룹에서 더 크게 올랐다
  (full +0.0050 / bbox +0.0069 vs 학습본 full +0.0036 / bbox +0.0057). 겨냥한 지점이 더 반응했다
  = "우연한 상승"이 아니라 "분포 이동을 고친 것"임이 확인됨.
- **예측대로 검증셋은 이 개선을 보지 못했다.** 검증셋 acc8 오프셋은 {0,2}뿐이라 우리가 산
  일반화를 시험할 수 없었기 때문. 만약 검증셋으로 판정했다면 이 +0.0040을 버렸을 것이다
  (R4 교훈이 다시 한번 결정적이었다).

## 사용한 코드 (개념)
```python
# transforms_bbox의 input*mask 직전에 삽입
def make_mask(W):
    p   = random_choice([4, 8])            # 50:50
    off = random_int(0, p)                 # 0..p-1 균등
    acs = random_int(26, 34)               # 관측 범위 균등
    m = zeros(W)
    m[arange(W) % p == off] = 1            # 등간격 격자
    c = W // 2; m[c - acs//2 : c - acs//2 + acs] = 1   # 중앙 대칭 ACS
    return m
# 무작위성은 (seed, epoch, fname, slice) 해시에서 유도 → 재현 가능
```
