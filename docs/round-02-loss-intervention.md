# Round 2 — 손실 함수 개입 (bbox 가중 / 고주파)

## 가설/목표
채점의 절반이 병변 박스(SSIM_bbox)이고 full과 bbox의 상관이 느슨하다(acc4 r=0.40, acc8 r=0.29).
그렇다면 손실 함수도 박스를 직접 강조하도록 바꾸면 오르지 않을까. 학습 목표와 채점 목표의
불일치를 교정하려는 시도.

## 변경한 것 (한 번에 한 변수, arm별)
백본 c4/ch9 12에폭 고정. arm을 순차 실행하고 게이트(+0.0010) 통과 시 다음 단계로 분기.
- A0_control: 원본 그대로.
- A1_bboxweighted: 박스 영역 손실 가중(--bbox-lambda 1.0) + bbox 기준 모델 선택.
- A2_hifreq: 고주파(edge) 손실 추가(--edge-beta 0.1).

## 결과 (results/round2_results.csv)

- 두 개입 모두 대조군보다 낮았다. 게이트 미통과로 후속 arm(조합, 병변 오버샘플링) 미실행.

## 판정
- 보류. 이 시점에서는 "손실 개입이 효과 없음"으로 보였다.
- 그러나 두 가지 요인이 겹쳐 있었다: (1) R1과 같은 12에폭 수렴 부족, (2) A1의 bbox 가중이
  기본 손실과 맞먹는 크기의 픽셀 L1(λ=1.0)로 구현되어 흐릿한 해를 유도한 점. 두 요인 모두
  이후 라운드에서 교정된다(R3에서 수렴, R5/R7에서 손실·데이터 재설계).

## 이 라운드에서 사용한 설정
- A1 플래그: `--bbox-weighted --bbox-lambda 1.0 --selection-metric bbox`
- A2 플래그: `--edge-loss --edge-beta 0.1`
