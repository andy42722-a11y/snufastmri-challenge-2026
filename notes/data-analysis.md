# 데이터 정밀 분석 기록

Round 5~7의 해법은 모두 데이터·코드 분석에서 나왔다. 그 분석 내용을 모은다.

## 1. 채점 구조 분석 (→ R5의 근거)
- recon_eval.py는 acc4/acc8을 따로 채점 후 반반 섞음 → 실질 4분면 각 25%.
- SSIM_full은 전경 마스크 안에서만 평균하는데, 학습 손실은 384×384 전체를 평균 → 불일치.
- 전경 비율은 볼륨마다 26~87%, 중앙값 약 50% → 학습 노력 절반이 채점 안 되는 배경에 낭비.
- 전경 밖 픽셀의 표준편차가 SSIM 안정화 상수보다 커서, 모델이 배경 잡음의 질감을 맞추려 함.
- 해법: 손실도 전경 마스크 안에서만 계산(채점식과 소수점 6자리 일치). → Round 5.

## 2. 샘플링 마스크 분포 분석 (→ R6의 근거)
- 마스크 구조 = 중앙 ACS 블록 + 바깥 등간격 격자. 변수는 (오프셋, ACS폭, W).
- 학습 acc8 오프셋은 {0,1,2}에 쏠림(0이 61%). 리더보드 acc8은 0~7에 고르게 분포.
- 리더보드 acc8 40볼륨 중 대부분이 학습에서 본 적 없는 오프셋을 사용(분포 이동).
- ACS 폭도 어긋남: 학습 {26,28,29,31,33,39}, 리더보드 최빈 30은 학습에 없음.
- 등간격 언더샘플링은 오프셋에 따라 위치가 달라지는 결맞은 앨리어싱을 만듦 → 미학습
  오프셋에서 복원이 무너지는 원인.
- 해법: 학습 시점에 마스크를 균등 생성해 오프셋·ACS를 고르게 커버. → Round 6.

## 3. k-space 완전 샘플링 확인 (→ R6 해법의 전제)
- 마스크 없이 raw k-space를 복원하면 정답과 SSIM=1.0(상대오차 약 1e-7) → 완전 샘플링.
- 고에너지 대역에서 mask==0/1 열 에너지가 사실상 동일. 0인 열은 최고주파 가장자리뿐.
- 따라서 어떤 언더샘플링 마스크든 학습 데이터에 씌울 수 있고, acc4 볼륨도 acc8로 변환 가능.
- 생성 가능한 마스크가 리더보드 조합의 약 96%를 자연히 포괄(미포괄은 학습에 없는 W=400 1볼륨).

## 4. 병변 분포 분석 (→ R7의 근거)
- 전체 4651 슬라이스 중 병변 박스가 있는 슬라이스는 1824장(약 39%).
- bbox는 박스 하나당 1표로 채점되며, win_size(7)보다 작은 박스는 제외.
- 가장 약한 칸은 bbox_acc8. 병변을 더 자주 보여주면 이를 직접 겨냥할 수 있음.
- 해법: 병변 슬라이스 오버샘플링(단순 복제 2배) + 대조군으로 스텝 증가 교란 분리. → Round 7.
- 관찰: 개선이 희귀 라벨에 크게, 이미 잘하던 상위 라벨에 소폭 → "이미 잘하는 것 더 복제는 낭비".

## 규정 준수 원칙
리더보드 데이터는 관찰만 허용되고 학습에는 쓸 수 없다. 마스크 증강은 리더보드 마스크를 직접
복사하거나 그 빈도를 하드코딩하지 않고, train/val의 샘플링 원리에서 균등 생성하는 방식으로만
구현했다.
